# Zion James' Portfolio 
**Created by:** Zion James
## Overview
Throughout this course, I made this repository so that it consists of my student portfolio website. 
This repository shows my coding skills, projects, featured content, and contact section.
Also, I have an "About Me" section to share some insight on my life and journey.
My portfolio has features that allow users to interact with buttons and links about the portfolio information.

## Languages and Technologies
-**CSS3:** Controls the colors, styling, and dark mode.
-**HTML5:** It provides the content and structureof the portfolio.
-**JavaScript:** This adds handles user input, interactive features, and dynamic skills.
- **Web Storage API:** 'localStorage' saves the dark mode preference and 'sessionStorage'
- store project information.
- **Git and GitHub:** You can host the project repository.

## Libraries and Frameworks
- No external JavaScript libraries or CSS frameworks are required.
- The portfolio uses CSS, standard HTML, and JavaScript.

## Dependencies
-Use a web browser: Google Chrome, Firefox, or Microsoft Edge.
- An internet connection for external links and remotely hosted images.
- Rememebr to check my images folder in the repository.

## How to Run
1. Open my repository on GitHub.
2. Either Download the repository or clone it to your computer.
3. Open the project folder.
4. Open `index.html` in a web browser.
5. Explore my portfolio.
